## 🎯 Overview

**DSS Enterprise Platform v3.5** is a full-stack, AI-powered **Decision Support System** built for Retail, E-Commerce, and Marketing domains. It transforms 4.17M+ rows of raw data across 22 datasets into prescriptive business intelligence — combining classical ML, explainable AI, generative AI, and a production-grade React dashboard.

> *"We don't just analyze the past. We prescribe the future."*

The system evolved through 3 phases:

Phase 1 → Data Science Core (Jupyter + SQLite + 13 ML Models)
Phase 2 → BI Dashboard (Streamlit + CustomTkinter)
Phase 3 → Enterprise Platform (React + Vite + FastAPI + Gemini AI)


### What makes it different from a typical analytics project?

| Capability | Typical Project | DSS Enterprise v3.5 |
|-----------|-----------------|---------------------|
| Analytics Type | Descriptive | ✅ **Prescriptive** |
| AI Explainability | ❌ Black Box | ✅ **SHAP XAI** |

| Statistical Validation | ❌ | ✅ **Bootstrap 10K iterations** |

| Frontend | Static reports | ✅ **React + Framer Motion** |

## ✨ Features

### 🧠 Prescriptive Analytics Engine (v3.5)
- **Risk Tolerance Slider** — adjust decision thresholds dynamically; GO/REVIEW/NO-GO counts adapt in real time
- **Counterfactual Analysis** — for any NO-GO scenario, the system tells you exactly what to change to make it succeed
- **Adaptive Grid Search** — skips weak scenario clusters, focuses compute on high-potential combinations (10× faster)
- **3-Tier Decision System** — GO (27.9%) / REVIEW (17.1%) / NO-GO (55.0%) across 2,400 simulated scenarios

### 🤖 AI & ML
- 13 trained ML models (Stacking, XGBoost, LightGBM, PyTorch, Random Forest, Gradient Boosting)
- SMOTE balancing for imbalanced churn datasets
- Two-stage CLV model (classifier + regressor, AUC 96.99%)

### 🔬 Explainable AI (XAI)
- SHAP TreeExplainer on all churn models
- Per-customer feature attribution waterfall charts
- Natural-language risk explanations exported to database

### 💬 NLP Sentiment Analysis
- 471,115 reviews from 18 sources processed with TextBlob
- LDA Topic Modeling — 10 auto-discovered topics
- TF-IDF keyword extraction with source-level sentiment breakdown

### 📈 Forecasting
- Holt-Winters Exponential Smoothing (trend + seasonality)
- ARIMA(1,1,1) time-series model
- 95% confidence interval bands on all forecasts

### 📣 Marketing Optimization
- 2,800 channel × segment × season × region × category combinations tested
- Bootstrap ROI validation: 10,000 iterations, 95% CI on every recommendation
- Before: −41.1% → After: +184.97% overall ROI

### 🌐 Generative AI Integration
- Google Gemini API converts KPI tables into executive narrative reports
- Nightly Batch Processor auto-generates tomorrow's insights at midnight
- On-Demand AI button for instant analysis on any dashboard page
- Response caching (24h TTL) to minimize API cost

### 🎨 Enterprise UI
- React 18 + Vite SPA — zero full-page reloads
- Framer Motion — 3D flip cards, neon-glow transitions
- Glassmorphism design system with dark-mode palette
- 12 specialized dashboard pages

## ⚙️ Installation

### Prerequisites

```bash
Python  >= 3.11
Node.js >= 18
Git
```

### 1 — Clone the Repository

```bash
git clone https://github.com/yossefayman/dss-enterprise-platform.git
cd dss-enterprise-platform
```

### 2 — Create and Activate Virtual Environment

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3 — Install Python Dependencies

```bash
pip install -r requirements.txt
```


Create a `.env` file in the root directory:


## 🤖 ML Models

### Churn Prediction Pipeline

```python
# Architecture used across all churn datasets
from sklearn.ensemble import (
    RandomForestClassifier,
    GradientBoostingClassifier,
    StackingClassifier
)
from xgboost import XGBClassifier
from lightgbm import LGBMClassifier
from imblearn.over_sampling import SMOTE

# Base estimators
estimators = [
    ('rf',  RandomForestClassifier(n_estimators=300)),
    ('xgb', XGBClassifier(n_estimators=300)),
    ('lgbm',LGBMClassifier(n_estimators=300)),
    ('gb',  GradientBoostingClassifier(n_estimators=200))
]

# Meta learner
stacking = StackingClassifier(
    estimators=estimators,
    final_estimator=LogisticRegression(),
    cv=5
)
```
